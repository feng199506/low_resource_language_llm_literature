# 数据流水线学习与设计指南

适用路线：A（现有基座持续预训练/指令微调）、C（从头预训练）。路线 B（检索与工具）的知识库构建也复用其中的“来源—授权—清洗—版本”环节。

阅读说明：
- 本指南只依据库内已下载并核验的资料，链接均指向本地文件。
- 论文结论均为作者在其实验条件下的报告。不同语言、文字、语料规模之间不能直接外推。
- 每篇论文涉及的语言、文字、资源条件，见 `catalog_cn.csv` 中的“涉及语言”“文字系统”“资源条件”列。
- 本指南不给出配置参数或硬件预算。

流程总览：

```
语料来源 → 授权与合规 → 语言识别 → 规范化/OCR 修复 → 去重 → 质量筛选 → 语言配比 → 数据版本与评测隔离
   04          04            05           05             05        05          05/07/01         05/15 + 工程
```

## 1. 语料来源（输入：目标语言清单；产出：候选来源表）

先回答三个问题：
- 目标语言在公开网页里有多少文本？
- 是否有高质量的非网页来源，如书籍、档案、政府出版物、广播转写？
- 有没有平行语料？

大规模多语言网页语料的构建方法与覆盖情况：
- 〔LRL-P-04-001〕FineWeb2：按语言调整处理流水线、覆盖上千语言。
- 〔LRL-P-04-002〕HPLT 扩展数据集：单语加平行语料。
- 〔LRL-P-04-005〕GlotCC：面向少数语言的 CommonCrawl 语料。
- 〔LRL-P-04-008〕IndicLLMSuite：一个语区从预训练到指令数据的完整蓝图。

非网页来源与数字化：
- 〔LRL-P-04-036〕拉科塔语档案 OCR 案例。
- 〔LRL-P-04-035〕Efik 语数字化语料。
- 〔LRL-P-05-016〕olmOCR：从 PDF 抽取训练文本。
- 〔LRL-P-05-037〕机构藏书语料流水线。

特定社区或语种的语料案例：
- 〔LRL-P-04-006〕MC²：中国少数民族语言。
- 〔LRL-P-04-038〕Esethu：科萨语的数据治理框架。

注意：
- “小语种”不等于“低资源”。有的语言使用人口少，但数字文本丰富；有的语言使用人口多，但网页文本稀少。
- 记录来源时，同时写明语言变体、文字（同一语言可能有多种文字）和文本是否自然产生。

## 3. 语言识别与近似语言区分（产出：带语言/文字标签的文档）

- 〔LRL-P-05-020〕CommonLID：在真实网页上重新评测语言识别系统。
- 〔LRL-P-05-019〕OpenLID-v3：提升近似语言区分精度。
- 〔LRL-P-05-047〕斯堪的纳维亚多标签语言识别。
- 〔LRL-P-05-049〕印度语言本文字识别。
- 罗马化与非正式书写：
  - 〔LRL-P-05-021〕与文字无关的语言识别。
  - 〔LRL-P-05-045〕非正式罗马化文本的语言识别。
- 语码转换文本：〔LRL-P-05-001〕MaskLID。
- 工程实现：
  - 〔LRL-E-02〕GlotLID 仓库。
  - 〔LRL-E-01〕datatrove 中的语言过滤步骤。

检查项：
- 语言识别模型对目标语言及其“近邻语言”的混淆情况。
- 同一语言不同文字的处理方式。
- 低置信度文档是丢弃还是另存待审。

## 4. 规范化、文字与 OCR 噪声（产出：规范化后的文本与规则记录）

- Unicode 与正字法：
  - 〔LRL-B-18-033〕The Unicode Cookbook for Linguists。
  - 〔LRL-P-05-033〕Don't Touch My Diacritics：讨论变音符处理不当对多语言模型的影响。
- OCR 后处理：
  - 〔LRL-P-05-035〕基于参考的历史文献变音符修复。
  - 〔LRL-P-05-036〕LLM 做 OCR 纠错的局限（No Free Lunches）。
  - 〔LRL-P-05-052〕哈萨克语 OCR 合成基准。
- 文字与跨语言迁移的关系（与第 6 类、第 2 类衔接）：
  - 〔LRL-P-02-054〕未知文字对跨语言迁移的影响。
  - 〔LRL-P-02-086〕罗马化预训练。

注意：
- 规范化规则（如 NFC/NFKC、变音符、零宽字符）会改变分词与去重结果，须在数据版本中固定并记录。

检查项：

- 数据版本要固定：来源快照、过滤规则、规范化规则、配比。
