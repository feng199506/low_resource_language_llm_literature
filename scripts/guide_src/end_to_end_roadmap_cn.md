# 端到端路线图：四种开发路线

四种路线：
- 路线 0：从零学习。
- 路线 A：适配现有基座。
- 路线 B：构建应用。

本图整合五份专题指南，每个阶段列出输入、产出、依赖和学习资料。

关于资源与效果：
- 本图不给出硬件预算、训练时长或效果承诺。
- 需要估计资源时，引用对应论文的模型规模、数据量与硬件条件，并注明不可外推。

## 横向依赖与常见陷阱

- 评测先于训练：先建好 A2 回归集，否则无法判断适配是否带来遗忘。
- 自然文本优先：机器翻译文本既可能混在语料里，也可能混在评测集里，见〔LRL-P-05-004〕〔LRL-P-09-057〕。
- 结果需复核：作者自报的结果须在自己的语言与数据上复核。
- 成本按语言计算：同样内容在不同语言下的 token 数可能差别很大，见〔LRL-P-16-034〕。
