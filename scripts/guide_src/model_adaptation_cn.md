# 模型适配学习与设计指南（路线 A：在现有多语言基座上增强小语种）

流程：基座评估 → 分词检查 → 持续预训练 → 指令微调（含合成/翻译数据）→ 偏好对齐与安全 → 遗忘与能力回归检查。

使用前请注意：
- 所有结论均为论文作者在其模型、语言与数据条件下的报告；“作者自报”与“独立复现”的区分，见 `catalog_cn.csv` 的“结果来源”列。
- 每个案例的语言与文字见“涉及语言”“文字系统”列。
- 本指南不给出超参数、算力预算或效果承诺。

## 1. 基座评估（输入：候选基座、目标语言评测集；产出：基座选择记录）

做什么：
- 用原生构建的目标语言评测（见 evaluation_cn.md）比较候选基座。
- 同时记录三项内容：分词效率、目标语言生成的流畅度与正确性、原有语言与代码能力的基线。

可参考的文献：
- 多语言基座的覆盖与能力不均衡：
  - 〔LRL-P-03-002〕Aya Model。
  - 〔LRL-P-03-023〕Sailor2（东南亚语言）。
  - 〔LRL-P-03-043〕Poro 34B（芬兰语加英语加代码）。
- 大规模语言覆盖：
  - 〔LRL-P-03-005〕EMMA-500。
  - 〔LRL-P-03-001〕MaLA-500。
  - 〔LRL-P-03-008〕Goldfish：为 350 种语言提供单语小模型，可作为对照基线。
- 多语言是否成为“诅咒”：〔LRL-P-03-009〕。
- 迁移规模规律：〔LRL-P-03-011〕ATLAS。

## 2. 分词检查与词表适配（产出：分词效率报告、是否扩表的决定）

先测量目标语言文本在基座分词器下的 token 数，与英语或同义平行文本对比，判断是否需要扩表或换分词器。

文献：
- 分词公平性：
  - 〔LRL-P-06-022〕Parity-aware BPE。
  - 〔LRL-P-06-014〕东南亚语言分词器实证。
  - 〔LRL-P-06-005〕形态复杂语言为何更难。
- 成本视角，与部署相关：
  - 〔LRL-P-16-033〕The Script Tax。
  - 〔LRL-P-16-034〕分词溢价的成本审计。
- 词表扩展与嵌入初始化：
  - 〔LRL-P-06-024〕。
  - 〔LRL-P-06-027〕用 0.01GB 目标语言数据扩表。
  - 〔LRL-P-06-077〕FOCUS（经典补充）。
  - 〔LRL-P-06-035〕ANGOFA。
  - 〔LRL-P-06-039〕渐进式词表扩展（阿拉伯语）。
  - 〔LRL-P-06-032〕零样本分词器迁移。
- 不扩表的替代：
  - 〔LRL-P-06-064〕RomanSetu（罗马化）。
  - 〔LRL-P-06-021〕MYTE（形态驱动的字节编码）。
  - 〔LRL-P-06-051〕Byte Latent Transformer（通用支撑）。
  - 〔LRL-P-06-015〕通用多语言分词器带来的“语言可塑性”。

工程：
- 〔LRL-E-03〕sentencepiece。
- 〔LRL-E-04〕tokenizers。

检查项：
- 扩表之后，新嵌入的初始化方式。
- 原有语言的分词是否被改变。
- 下游评测要同时覆盖目标语言与原有语言。

## 3. 持续预训练（产出：目标语言适配后的基座 + 训练与数据记录）

  - 〔LRL-P-07-018〕大规模跨语言持续预训练。
- 学习率重热、重放等通用策略：〔LRL-P-07-001〕Simple and Scalable Strategies to Continually Pre-train（通用支撑）。
- 语言适配中的能力涌现：〔LRL-P-07-016〕，涉及巴斯克语、阿拉伯语、印尼语。
- 具体语言案例：

- 机器翻译：见第 5 节。

## 7. 遗忘与能力回归检查（产出：前后对比报告）

每个阶段结束后，至少比较三类能力：
1. 目标语言的理解、生成与推理（原生构建的基准）。
2. 原有高资源语言（通常是英语）的同类能力。
3. 代码与工具调用能力：如果产品需要，参见 evaluation_cn.md 的代码/工具评测。

文献依据：
- 遗忘相关：〔LRL-P-01-060〕、〔LRL-P-07-006〕、〔LRL-P-08-013〕。
- 推理与回答语言不一致：〔LRL-P-11-034〕。
- 控制思考语言的代价：〔LRL-P-11-016〕。

工程：
- 回归评测：
  - 〔LRL-E-18〕lm-evaluation-harness。
