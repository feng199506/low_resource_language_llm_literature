# 通用小语种与低资源语言大语言模型开发资料库

检索与下载日期：2026-10-29（UTC）。本库独立于本机其他资料库管理，本轮只收集、下载、核验、整理资料，不训练模型，不部署服务。

本库支持三条开发路线：
- A：在现有多语言基座上，通过持续预训练、指令微调与对齐增强小语种能力。
- B：现有模型结合本地知识库、检索与工具，开发对话助手与编程智能体。
- C：理解从头训练语言模型所需的数据、架构、算力与工程条件。

不指定目标语言。“小语种”不等于“低资源语言”：每篇论文实际涉及的语言、语系、文字系统与资源条件，在 `catalog_cn.csv` 中逐条记录；未核实的写“待核实”。

## 4. 文件命名与语言后缀

自行创建、下载和交付的文件，在扩展名前加语言后缀：`_en`（英文）、`_cn`（中文）、`_cn_en`（中英双语）。

源码仓库、完整网站（HTML 书）有固定文件名要求，处理方式如下：
- 原始结构的完整归档包为 `*_original_en.tar.gz`。归档文件本身标注语言，解压后可离线阅读或查看原始仓库。
- 同名目录内是文件名加了语言后缀的副本，文件内容不变，附 `path_map_en.csv`（原路径 → 新路径 → SHA256）。
- 这份副本只供阅读检索：链接与导入路径未改写，不能直接作为可运行仓库或网站使用。

例外：`scripts/state/` 下的进程锁文件由脚本运行时生成，已改为 `*_en.lock` 命名。

## 5. 核验标准

- **论文**：
  - 硬检查：HTTP 200、`%PDF-` 文件头、pypdf 可解析、≥4 页、可抽取字符 ≥12000、非补充材料。
  - 软检查：首两页标题匹配 ≥0.8、首作者姓氏出现、存在参考文献标题。
  - 软检查不过的条目，用 `text` 命令人工核对首页后才计入。共 6 篇，核对内容写在 `核验详情` 列。
- **课程**：官方已发布的讲义全部下载成功才计入；`completeness_note` 写明官方讲数与未发布部分。
- **书籍**：主 PDF 页数、首页标题、目录、作者都要核对；分章节开放的书下载全部章节；HTML 书做离线镜像并校验目录页。
- **工程项目**：浅克隆固定的 tag 或提交号，不执行仓库代码。剔除权重、数据集、二进制和大于 5MB 的文件，并记录剔除清单。文档集的目录解析率达到 95% 以上才计为完整文档集，否则如实标“否”。

## 7. 使用 catalog_cn.csv 的注意事项

- 小语种字段（涉及语言、语系、文字、资源条件、基座、适配方式、数据、翻译/合成/教师依赖、人工评价、能力影响、资源与可用性、评测、基准来源、污染控制、局限）的依据写在“字段依据”列：摘要、正文（含页或节）或官方文档。
- 前 10 篇优先阅读的论文多数看过正文，其余以摘要为主。
- 未核实的字段写“待核实”。其中“基准来源”有约 400 条为“待核实”，使用前须回到原文核对。
- 结果来源：943 篇为作者自报，只有 1 篇明确为独立复现。引用前须在自己的语言与数据上复核。
- 证据范围：通用方法证据 520、特定语言案例证据 267、两者兼有 199。
- 发表状态仅依据 arXiv 元数据（journal_ref 与注释）和来源页面；未逐篇查询正式发表记录，“预印本（未核查正式发表）”不代表未发表。
